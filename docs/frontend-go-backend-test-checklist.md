## 1️⃣ 认证与访客功能

### 1.1 访客模式进入
- [ ] 打开首页，看到「访客模式」界面
- [ ] 输入昵称（如：测试用户A）
- [ ] 点击「立即进入」
- [ ] **预期**: 成功进入房间，看到播放器界面
- [ ] **检查**: 右上角显示昵称

### 1.2 访客升级横幅
- [ ] 进入后看到顶部升级提示横幅
- [ ] 横幅显示：「当前为访客模式，使用邀请码注册后可跨设备同步」
- [ ] 点击「立即注册」按钮
- [ ] **预期**: 弹出升级模态框
- [ ] 点击「取消」可以关闭

### 1.3 管理员登录
- [ ] 刷新页面或清除 Cookie 返回登录页
- [ ] 点击「管理员登录」
- [ ] 输入：用户名 `admin`，密码 `TestPassword123!`
- [ ] 点击登录
- [ ] **预期**: 成功登录（如果提示错误，记录错误消息）
