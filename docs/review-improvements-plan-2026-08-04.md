### ⚠️ 高优先级待实施

#### 1. 安全：添加依赖扫描到 CI
**问题**: 缺少自动化依赖漏洞扫描  
**影响**: 可能使用有漏洞的依赖包  
**方案**: 
- 添加 `govulncheck` 到 GitHub Actions
- 添加 `npm audit` 到 CI pipeline
- 每日自动运行

#### 2. 文档：添加架构文档
**问题**: 缺少 `docs/architecture.md`  
**影响**: 新开发者难以快速理解系统设计  
**方案**:
- 绘制系统架构图
- 说明各模块职责
- 记录技术决策

#### 3. 测试：添加 E2E 测试
**问题**: 缺少端到端测试  
**影响**: 重大重构时信心不足  
**方案**:
- 使用 Playwright 或 Cypress
- 覆盖核心用户流程（访客进入 → 听歌 → 升级）
